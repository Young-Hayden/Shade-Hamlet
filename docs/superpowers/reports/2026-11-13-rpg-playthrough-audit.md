## 2. 试玩验证通过的功能

- **剧情全流程**：长老对话线索 1 → 家书线索 2 → 偷听线索 3 → `ConfrontReady` → 队长走到井边 → 自动对峙 → 听完真相 → 放走结局；结局后 `timeScale=1`、主角控制恢复、光标重新锁定。
- **刺杀**：背后 1m、Patrol 目标、面向敌人 → `TryAssassinate` 成功，目标 HP 0 死亡。队长未解锁前 `allowKill=false`，不可刺杀（符合设计）。
- **弓箭手**：近战反击（贴身 1.4m 每 2 秒扣 5），拉开距离后进入远程，箭周期性生成、玩家每 2 秒扣 5；弓始终贴手。
- **潜行**：潜行状态 `Sneaking`，120 帧位移约 0.79m（对应 2.2m/s）；进入 `HiddenArea_0` 后 `Status=Hidden`。
- **战斗**：普通右键攻击使弓箭手 HP 100 → 80。
- **烟雾/药水**：烟雾激活并进入冷却；受伤后用药水 HP 65 → 95、库存归零。
- **暂停**：打开后 `timeScale=0`、光标解锁；关闭后恢复。
- **武器离手扫描**：Hero 细剑 0.46m、Archer 弓 0.14m、Enemy/Elder 剑 0.52m，均在合理范围。

## 3. 仍存在的问题（按严重度）

### P2 建议修复

1. **主角头顶世界空间血条过宽**：近景下横贯半屏，遮挡角色与房屋；应缩小宽度或改为只在战斗/受伤时显示。
2. **潜行仍播放普通走路动画**：速度降到 2.2m/s 但动画频率不变，出现滑步感；建议加潜行动画状态或按速度缩放动画速度。
3. **攻击动画是双手剑动作，武器却是单手细剑**：动作与武器不匹配，刺杀/挥剑时视觉违和；建议换单手细剑动画或调动画。
4. **弓箭手不会主动保持射程**：`chaseStoppingDistance=6.5` 只在追击时生效，近身后会贴身近战，缺少后撤行为；属于 AI 行为缺口，不是显示 bug。

### P3 观感/素材问题

5. **草丛与灌木在夜景中呈黑色尖刺剪影**：夜间光照与素材共同造成，影响潜行区观感。
6. **灯笼挂钩没有连接臂**：贴墙灯笼有悬空感，需加短横杆。
7. **部分房屋从上方可看穿屋顶**：Synty 模型本身无内顶，非本轮引入。
8. **静态 UI 扫描报 `Order/Button (Legacy)` 越界/重叠**：该报告基于编辑器 GameView 实际分辨率（非 1920×1080），需进一步确认是否真越界，暂列待核查。
