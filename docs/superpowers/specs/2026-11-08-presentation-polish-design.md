# RPG_Project 表现层修复设计

日期：2026-11-08
状态：方案 A 已获用户批准

## 目标

在不改变战斗数值、敌人仇恨规则和现有美术资源的前提下，改善相机操作、头顶血条和画面亮度。

## 范围

1. 修改 `Assets/Script/HeroCamera.cs`：
   - 滚轮缩放，距离限制为 4～12 米。
   - 按住鼠标中键拖动进行水平旋转。
   - 右键继续专用于选敌攻击，左键继续点地移动。
   - 保留当前俯视角度和 SmoothDamp 跟随。
   - 使用简单遮挡检测，降低镜头穿入建筑的概率。
   - 新序列化参数提供兼容现有场景的默认值。
2. 修改并保存 `Assets/Scenes/RPG游戏.unity`：
   - 主角与敌人的世界空间血条降低悬空高度，尺寸缩小约 20%。
   - 保留原 Canvas、Slider、HPScript 引用和朝向逻辑。
   - 光照只小幅提高环境补光与方向光亮度，单项调整不超过约 15%。
3. 输出同视角前后截图与实测结果。

## 非目标

- 不修改敌人主动/被动仇恨、攻击力、血量或攻击距离。
- 不增加装备、任务、技能、重生、命中特效等新玩法系统。
- 不更换地形树材质，不修改烘焙后端、画质等级、阴影距离、天空盒或共享材质。
- 不修改开始界面和 `CLick.cs`。

## 实施与回滚

- 修改代码前备份 `HeroCamera.cs`。
- 第一次写场景前备份 `RPG游戏.unity`，血条和光照分别执行、分别验收。
- 若光照过曝或明暗层次变差，只还原光照数值，不回滚血条。
- 项目无 Git 仓库，采用带时间戳的文件备份作为回滚路径。

## 验证

1. 编译无错误，Play 模式无新增异常。
2. 滚轮到达 4 米和 12 米时不越界；松开中键后相机不继续旋转。
3. 中键旋转不会触发攻击；右键仍能追击并伤害敌人。
4. 左键仍能点地移动，点击 UI 不驱动角色。
5. 两条血条均可见、不镜像、不遮挡角色头部，伤害后数值正常变化。
6. 使用相同主角位置和相机方向截取修改前后画面。
7. 停止 Play 后确认只保留设计内的场景改动。

## 后续仅提供建议
