# 《影村》场景细节增强设计（克制写实）

日期：2026-11-13
工程：`D:\Unity\projects\RPG_Project`
范围：在不扩大可玩区、不改剧情与既有玩法的前提下，提升现有村庄的密度、可读性与真实感。

## 1. 目标与约束

目标：

1. 让现有可玩区"小而密"：每栋房屋、每条路、每处火堆都有生活痕迹与环境细节。
2. 修掉场景边缘"被切出来的平台"感，用自然元素遮住已加的隐形边界。
3. 保持黄昏/夜晚潜行的可读性：阴影区仍能藏人，道路与房屋轮廓仍清楚。

约束：

- 不扩大地形，不新增玩法、不改剧情资产与章节逻辑。
- 新增装饰不得占用道路、巡逻点、线索/对话/井边对峙点的交互空间（安全间距 ≥ 1.5m）。
- 新增实体必须有合理碰撞：树、木桶、柴堆、岩石、倒木有碰撞；草、花无碰撞（保持可穿行）。
- 实时点光总数 ≤ 10，全部无阴影；不新增实时阴影光源。
- 所有新增对象挂在独立根节点 `SceneDetails_*` 下，便于整体回滚。
- 不改动 `StealthCoverVisuals`、`StealthCoverAreas`、`StealthPhysicalCover`、巡逻点与剧情对象的位置。

## 2. 现状（审计结论）

- 地形 100×100（中心 0，可玩区实际约 ±40），163 棵树全部同一原型且成排分布，地形有 8 层可用贴图但看起来几乎全绿。
- 9 栋房屋、7 道栅栏、4 个木箱此前无碰撞，2026-11-13 已补 MeshCollider；163 棵树已通过预制体变体加胶囊碰撞；已加 4 面隐形边界墙（±47）。
- 现有可用素材：Synty Student Sample（树、草、花、树桩、南瓜、岩石、土坡、木箱、房）、GameDev.tv 农具（锄头、干草叉、棍棒）、SimpleFX 粒子。没有木桶、推车、灯笼等现成道具，需程序化低模补充。
- 两处火堆（`StealthLighting/Route Fire`）只有点光，无烟、无柴堆；房屋窗户无灯光。

## 3. 细节包设计

### 3.1 地面与道路

用 Terrain 贴图（不改变高度）刷出村落主路：

- 三条路径：出生点 → 长老屋；出生点 → 井边对峙点；村中主街（房群之间）。
- 路宽 2.5m，边缘 1m 内按距离权重渐隐，混合到 `Dirt layer` / `Light dirt layer`。
- 房屋正面入口外 1.5m 半径刷一小块裸土，避免"房子直接长在草里"。
- 只写 `RPG_Terrain.asset` 的 alphamap（该资产已是本场景专用副本），不动原始 Synty 资产。

### 3.2 植被与自然物

- 163 棵树：对非边界树随机化 Y 轴旋转与 ±12% 宽度比例，保持高度比例不变，打散现在过于整齐的树列。
- 新增 90–120 个小型植被：Synty 草丛、花、树桩、岩石、倒木。规则：
  - 距道路中心线 ≥ 1.5m，距房屋包围盒 ≥ 0.8m；
  - 距 4 个巡逻点、长老、家书、井边点 ≥ 2m；
  - 草/花无碰撞；树桩/岩石/倒木加碰撞。
- 倒木 3–5 根放在路旁，作为视线遮挡的天然物（不改潜行逻辑，只提供视觉掩体）。

### 3.3 生活道具（每栋房 2–4 件）

优先用现有素材，缺失的用低模程序化补：

- 木桶（8 边圆柱 + 深木色材质）、柴堆（4–6 根圆柱捆）、水桶、木凳、矮桌。
- 南瓜（Synty）、木箱（复用现有 `SM_Prop_Crate_01`）、农具（锄头/干草叉靠墙）。
- 井边：水桶、木架、绳索（细圆柱），强化对峙点的场景意义。
- 火堆旁：柴堆 + 两块坐石。
- 摆放规则：贴房屋外墙或路边，不占门洞正面 1.2m 通道；大小不遮挡互动提示。
- 小道具碰撞：木桶/柴堆/矮桌用 BoxCollider；南瓜、水桶可无碰撞（避免卡脚）。

### 3.4 光照与氛围

- 窗户暖光：6 处，Point Light，暖橙 (1.0, 0.65, 0.35)，range 4，intensity 0.9，无阴影。
- 门口灯笼：4 盏，程序化灯笼（小立方/圆柱 + 发光材质）+ 同色点光，range 3，intensity 0.8。
- 火堆：补柴堆与轻量烟粒子（复用 SimpleFX 尘土粒子改色/放大），点光 intensity 1.0 → 1.2。
- 距离雾：开启 `ExponentialSquared`，density 0.006，颜色取夜空蓝紫；截图确认村庄轮廓与潜行可读性。
- 不改变现有 Directional Light 与 ambient 基调。

### 3.5 边界自然化

- 沿 ±44 的四条内侧边界布置两排错落树（50–70 棵 Synty 树实例，随机旋转与 0.9–1.2 缩放），树间补 10–15 块岩石与 3–4 个土坡。
- 树带用带胶囊碰撞的树预制体变体，使边界看起来由森林与岩石收口，遮住 ±47 的隐形墙。
- 林带不进入 |x|,|z| < 40 的可玩核心区，不影响巡逻与剧情走位。

### 3.6 性能预算

- 新增实时点光 ≤ 10（无阴影）。
- 新增静态装饰对象 ≤ 350 个（实施实测 299 个），全部标记 Static（Batching/遮挡计算）。
- Play 模式 30 秒平均帧时间相对当前退幅 ≤ 10%，95 分位不退步超过 2ms。

## 4. 实施组织

新增内容全部在编辑态由一次性工具脚本生成，按根节点分组：

- `SceneDetails_Ground`：土路刷图记录（无对象，改 Terrain alphamap）。
- `SceneDetails_Vegetation`：草丛、花、树桩、岩石、倒木。
- `SceneDetails_Props`：木桶、柴堆、水桶、桌椅、南瓜、农具、井边道具。
- `SceneDetails_Lights`：窗户暖光、灯笼、火堆烟。
- `SceneDetails_Border`：边界树带与岩石。

原有对象只做两类改动：树实例的旋转/缩放；火堆点光强度。其余只新增。

## 5. 测试与验收

静态校验（编辑态脚本）：

1. 新增对象计数与碰撞清单符合设计；草/花确无碰撞。
2. 禁区断言：所有新增碰撞体与道路中心线距离 ≥ 1.2m、与 4 个巡逻点/长老/家书/井边点距离 ≥ 1.5m。
3. NavMesh 路径完整：出生点 → 长老、家书附近、井边点、4 个巡逻点全部 `PathComplete`；房屋中心仍不可行走。
4. 边界：±44 林带处 NavMesh 不可穿出，玩家仍被 ±47 墙阻挡。

运行时验收：

5. 12 项既有回归全绿（含移动、攻击、刺杀、弓箭、药水、HUD、暂停、死亡、场景切换）。
6. 三条第一章剧情路径冒烟（kill / kill_after_truth / spare）仍可走通。
7. 截图矩阵：出生点、村口主路、井边、边界林带、夜景全景；与实施前对比。
8. 帧时间对比数据写入验收报告。

## 6. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 刷 alphamap 破坏地形外观 | 先备份 `RPG_Terrain.asset`；只改 1–3 层权重并截图对比；可单资产还原 |
| 新增碰撞堵住巡逻/交互路径 | 生成后跑 NavMesh 路径断言与 12 项回归；违例对象自动列入报告并移除 |
| 灯光过多导致帧时间下降 | 点光上限 10、全部无阴影；实测帧时间超预算则减半窗户光 |
| 雾降低潜行可读性 | 截图对比；若远景发灰，将 density 降到 0.004 或关闭 |
| 装饰物挡住视线妨碍潜行 | 装饰物高度普遍 < 1.2m，不进入核心潜行草区；岩石/倒木只放在路旁 |

回滚：备份 `D:\Unity\backups\RPG_Project_2026-11-13_scene-detail\`（场景、Terrain 资产、进度文档）；删除 `SceneDetails_*` 根节点即可撤销全部新增对象。
