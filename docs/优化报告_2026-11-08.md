## 二、修复后实测结果

- **战斗闭环**：选中巡逻中的敌人 → 主角追上并贴近 → 连续出刀，敌人 100→80→60→40→20→0；敌人被打后反击，主角 100→80；敌人死亡动画正常、尸体原地不动、2 秒后销毁、主角自动收刀回 Idle。
- **死亡回归**：连续两次 1000 点致命伤害只结算一次，HP=0（不负数），尸体位移 0.000，2 秒后销毁，相机不报错。
- **场景往返**：`RPG游戏 → 界面 → RPG游戏` 均成功。`界面.scene` 这个非标准扩展名实测可用，不是 Bug。
- **性能**：帧时间 avg 4.90ms / p95 5.39ms（约 200 FPS，Ultra 画质）。**性能不是瓶颈**，不建议为"优化"而盲目降画质或改渲染设置。

## 三、仍未处理（需要拍板，涉及外观或美术资产）

1. **地形树告警**：`SM_Env_Tree_03 must use the Nature/Soft Occlusion shader`。163 棵树的原型用的是共享的 Synty `PolyAdventureMaterial_01 (Standard)`。要消告警得给树单独做 Soft Occlusion 材质，但 Soft Occlusion Leaves 依赖顶点色/裁剪，Synty 低模树换上去可能外观变坏，所以没动。目前树渲染看起来正常。
2. **光照烘焙后端告警**：`Failed to set bake backend because only progressive GPU lightmapper is available`，出现在编辑器恢复场景时；当前 LightingSettings 已是 ProgressiveGPU，已有 1 张烘焙光照贴图。不影响运行，未改。
3. **一次性 Missing Script 提示**：场景切换时出现过一次，但对两个场景做全量扫描均无丢失脚本，未复现。
4. **手感/视觉可选增强**：相机不能旋转缩放（只能固定跟随）、血条悬空偏高、画面偏暗偏绿、退出按钮红字对比差、没有受击/命中特效、敌人只有被动反击（可改主动仇恨范围）。
